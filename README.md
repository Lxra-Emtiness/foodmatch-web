# 🍜 FoodMatch

## โปรเจกต์ทำอะไร
FoodMatch เป็นเว็บแอปพลิเคชันช่วยผู้ใช้เลือกเมนูอาหาร โดยสามารถค้นหาเมนูตามงบประมาณ รสชาติ วัตถุดิบ และประเภทอาหาร พร้อมระบบสุ่มเมนู รายการโปรด และประวัติการค้นหา

## วิธีใช้งาน
1. เข้าเว็บไซต์ FoodMatch และเลือกเมนูที่ต้องการใช้งาน
2. กรอกงบประมาณ พร้อมเลือกรสชาติ วัตถุดิบ และประเภทอาหาร
3. กดค้นหาเพื่อดูเมนูที่ตรงกับความต้องการ
4. สามารถสุ่มเมนู เพิ่มเมนูโปรด และดูประวัติการค้นหาได้
